Entry for the make.fun competition [Midnight Fridge Roast](https://make.fun/c/u-carbon-forge-midnight-fridge-roast-fc5d44a7).

The program writes one line roasting a smart fridge that refuses to open after midnight to `/output/entry.txt`.

Run it with:

```sh
python3 -P -s main.py
```
